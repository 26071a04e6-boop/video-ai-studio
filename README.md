# Video AI Studio

A Next.js app prototype for AI-assisted video editing and enhancement.

## Features implemented

- reference video upload UI
- input image upload UI
- AI-style project configuration panel
- processing pipeline overview
- enhancement workflow section
- responsive landing page layout

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes

This is a front-end MVP and API scaffold for a reference-video-based image-to-video workflow and poor-quality-to-high-quality enhancement product.
